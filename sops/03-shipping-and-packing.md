# SOP 03 — Shipping & Packing

Covers customers who want **us to ship an item via USPS** — including quoting,
packing, and creating the label.

> **We ship through USPS only.** We are not a UPS/FedEx/DHL outlet. If a customer
> needs another carrier, we can't create that label — refer them to that
> carrier. We *can* accept their **prepaid** UPS/FedEx/DHL drop-offs and
> Amazon/QR returns only when they route through USPS (see
> [SOP 04](04-dropoffs-and-returns.md)).

## 1. Intake & qualify the shipment

Ask, in order:
1. **Where is it going?** (ZIP / country — domestic vs. international changes
   everything.)
2. **How fast does it need to arrive?** (Sets the service level.)
3. **What's inside, and what is it worth?** (Sets packing method and insurance,
   and screens prohibited items.)
4. **Is it fragile?** (Sets packing materials.)

### Prohibited / restricted — never ship without checking

Politely refuse or escalate anything that may be prohibited. Common ones:
- Hazardous materials, lithium batteries loose/damaged, flammables, aerosols,
  ammunition, fireworks.
- Perishables without proper packaging.
- Cash, and most carriers prohibit it.
- Cannabis/CBD, alcohol, tobacco, firearms — **only** if we are authorized and
  the carrier allows it. When in doubt: **`[CONFIRM: store policy]`**, ask the
  manager.

If the customer won't say what's inside, we don't ship it.

## 2. Weigh, measure, quote

1. Place the **packed** item (or estimate the final packed size) on the scale.
   Pricing is based on the *final* package, not the bare item.
2. Measure L × W × H. Note any dimension over `[CONFIRM]` may trigger
   oversize/dimensional pricing.
3. Pull live USPS rates for the requested speed and present the options plainly:
   **service (Ground Advantage / Priority / Priority Express / Media Mail),
   estimated delivery, price.**
4. Offer the best value for their need; let the customer choose.
5. **Quote the all‑in price** (postage + packing materials + any insurance +
   our service fee `[CONFIRM]`) *before* charging.

## 3. Packing standards

Pack so the item survives a 3‑foot drop. General rules:
1. Use a sturdy box appropriately sized — not too big, not too tight.
2. **2 inches of cushioning** on all sides for fragile/valuable items (bubble
   wrap, peanuts, foam, paper).
3. Wrap each fragile item individually; isolate items so they can't touch.
4. Fill all voids so nothing shifts when shaken.
5. Seal with **pressure‑sensitive packing tape** (H‑taped seams). No masking
   tape, no string, no cellophane.
6. Remove or cover all old labels and barcodes.
7. For documents/photos, use a rigid mailer.

**Packing materials are charged** per the price list `[CONFIRM]`. If we pack it,
we stand behind the packing for insurance purposes — so pack it right.

## 4. Insurance / declared value

1. For anything valued over **`[CONFIRM: $100]`**, offer insurance and explain
   the cost.
2. Note carrier‑specific rules (some categories are non‑insurable; some require
   professional packing for a valid claim).
3. Record declared value in the system. Keep packing notes for high‑value items
   in case of a claim.

## 5. Create the label & complete

1. Enter the address carefully. **Verify spelling and ZIP**; use address
   validation. Read the recipient address back to the customer.
2. Generate and print the label; affix it flat, fully, on the largest flat
   surface (no tape over the barcode).
3. Charge the customer, hand them the **receipt with tracking number**, and tell
   them how to track.
4. Staple/record the tracking to the receipt copy if we retain one.
5. Place the package in the USPS outbound staging area.

## 6. Hand‑off

- Packages must be staged before the USPS dispatch cutoff (see
  [README hours](README.md)).
- Run the USPS CPU end‑of‑day so packages show as accepted (see
  [SOP 02](02-closing-procedures.md) and [SOP 05](05-usps-cpu.md)).

> **Golden rule:** Quote before you charge. Verify the address. Pack for a drop.
> Every package leaves with a tracking number.
